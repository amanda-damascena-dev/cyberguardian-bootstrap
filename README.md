# CyberGuardian

Página responsiva sobre segurança digital, desenvolvida para praticar o sistema de grid e os breakpoints do Bootstrap 5.

## Funcionalidades

- Layout adaptável para celulares, tablets e computadores
- Conteúdo organizado em cartões responsivos
- Aplicação do sistema de grid do Bootstrap
- Utilização dos breakpoints `col-12`, `col-md-6` e `col-lg-4`

## Tecnologias utilizadas

- HTML5
- Bootstrap 5
- Design responsivo

## Como executar

1. Clone este repositório.
2. Abra a pasta no VS Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.
